Status pill

Shows the state of a document, request, application or payment. Always icon + label + color, so color is never the only signal.

Deadline marker

Shows when something is due. It is separate from the state: a Needed item can also be overdue. Overdue is the only solid red element in the portal.

Needed Overdue by 2 days The marker sits next to the state; it never replaces it.

Button

One primary action per screen. Say exactly what happens: "Upload document", not "Submit". Comfortable is 48px high for the client portal; Compact is 36px for staff.

Document upload slot

Camera-first for phones, with the requirement visible at the point of upload. Uploads resume after a lost connection. A rejected document always shows the reason and a new deadline.

Stage tracker

Shows where the case is across a 6 to 18 month journey. Progress uses the brand color, not status green. The summary is for the dashboard; the full list is for the case page.

Banner

For messages about the whole page or case. Four tones reuse the status colors. Use sparingly: one banner per screen.

Timeline

A running history of the case. It answers "what is happening?" without a phone call. Most recent first. Dates are absolute plus relative.

Message thread

Secure messages tied to the case. They replace email back-and-forth. Incoming messages align to the start, the client's own to the end, so the layout mirrors automatically in a right-to-left language.

Empty state

Used when there is nothing to show. For long waits, it reassures: it says what is happening and what the client should do (often nothing).

Review panel (staff)

Where a document specialist approves or rejects a file. Compact density. A rejection needs a reason and a new deadline, and shows a preview of the message the client will see.

Illustrations

Line illustrations use the text color for outlines and the brand tints for fills. Decorative: hidden from screen readers.

Path chart

A smooth curve with one highlighted point and a dark tooltip. On a client dashboard it shows the case journey; on the staff console it shows weekly volume. The chart always has a text alternative, and scrolls sideways on narrow screens instead of shrinking its text.

Table card, tabs and switch

Staff work lists: a title, tabs, a search field and a switch above a data table. The table scrolls sideways on narrow screens. Row actions name the row for screen readers.
